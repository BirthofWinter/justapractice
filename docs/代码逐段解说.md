## 先认识贯穿项目的量

| 符号或形状 | 意义 |
| --- | --- |
| B | 当前批次样本数，最后一个批次可能较小 |
| T=24 | 每段动作帧数 |
| J=5 | 每帧关节数 |
| `[B,24,5,2]` | 一批动作；最后一维依次是 x、y |
| `[B,240]` | 同一批动作展平成向量 |
| `[B,3]` | 类别的 one-hot 条件 |
| 参数 | 网络通过训练更新的权重和偏置 |
| 超参数 | 人设置的隐藏维、学习率、轮数、损失权重等 |

基础流程：类别 → 网络预测动作 → 与目标比较得到损失 → 求梯度 → Adam 更新参数。训练修改的是网络参数，不是类别和标准答案。模型起初不懂骨架或动作，是损失逐步引导输出接近目标。


## 第一章：先理解数据

这个文件决定“题目”和“标准答案”如何产生。这里只模拟一条含 5 个点的二维关节链，并没有读取真实手语数据。

- `math` 计算三角函数；NumPy 生成坐标和随机数；PyTorch 把数据交给网络；`Dataset` 定义数据集接口。
- `GLOSS_NAMES` 给类别编号命名：0 抬手、1 挥手、2 指向。`NUM_GLOSSES=3` 是类别数。
- `NUM_FRAMES=24` 是每段动作的帧数，`NUM_JOINTS=5` 是每帧的关节数，`POSE_DIM=10` 是每帧的坐标数。
- 一个 `pose` 的形状是 `[24,5,2]`。`pose[t,j,0]` 是第 t 帧第 j 个点的 x 坐标，最后一维的 1 对应 y。

#### `__getitem__`

原文件：`src/data.py`，第 22 行起。

```python
def __getitem__(self, index):
    rng = np.random.default_rng(self.seed + index)
    gloss = int(rng.integers(0, NUM_GLOSSES))
    side = float(rng.choice([-1.0, 1.0]))
    scale = float(rng.uniform(0.85, 1.15))
    root_shift = float(rng.uniform(-0.06, 0.06))
    speed = float(rng.uniform(0.8, 1.25))
    pose = make_pose(gloss, side, scale, root_shift, speed)
    extra = np.array(
        [side, (scale - 1.0) / 0.15, root_shift / 0.06],
        dtype=np.float32,
    )
    return {
        "gloss": torch.tensor(gloss, dtype=torch.long),
        "extra": torch.from_numpy(extra),
        "pose": torch.from_numpy(pose),
    }
```

1. `default_rng(self.seed + index)` 为每个编号建立固定的随机数发生器。同一个数据集的同一编号每次得到相同结果；打乱读取顺序不会改变该样本。
2. `gloss` 在 0、1、2 中选择；`side` 取 -1 或 1，控制水平方向；`scale` 控制四段骨骼的长度；`root_shift` 控制根节点水平位置；`speed` 改变动作的时间进程。
3. `make_pose(...)` 根据这些参数生成标准答案，而非模型预测。
4. `extra` 把方向、尺度、位移放进长度为 3 的数组。后两项经过缩放，落在约 [-1,1] 内，避免三个条件的数值范围差得太多。`speed` 没有放入条件。
5. 返回字典：`gloss` 是 `long` 类型的标量张量，`extra` 为 `[3]`，`pose` 为 `[24,5,2]`，后两者是 float32。`from_numpy` 在这里与数组共享内存；样本生成后不再改动数组。

DataLoader 会把多个字典按同名字段堆叠，B 个样本变为 `gloss:[B]`、`extra:[B,3]`、`pose:[B,24,5,2]`。

#### `make_pose`

原文件：`src/data.py`，第 41 行起。

```python
def make_pose(gloss, side=1.0, scale=1.0, root_shift=0.0, speed=1.0):
    frames = np.linspace(0.0, 1.0, NUM_FRAMES, dtype=np.float32)
    phases = np.power(frames, speed)
    lengths = np.array([0.20, 0.18, 0.12, 0.10], dtype=np.float32) * scale
    poses = np.zeros((NUM_FRAMES, NUM_JOINTS, 2), dtype=np.float32)

    for frame_index, phase in enumerate(phases):
        if gloss == 0:
            angles = [0.65 - 1.8 * phase, 0.10, 0.08, 0.05]
        elif gloss == 1:
            angles = [
                -0.35,
                0.25,
                0.25 + 0.65 * math.sin(2.0 * math.pi * 2.0 * phase),
                0.10,
            ]
        else:
            angles = [-0.15, -0.10, -0.05, -0.10]

        x, y = 0.50 + root_shift, 0.78
        poses[frame_index, 0] = (x, y)
        for joint_index, (length, angle) in enumerate(zip(lengths, angles), start=1):
            x += side * float(length) * math.cos(angle)
            y += float(length) * math.sin(angle)
            poses[frame_index, joint_index] = (x, y)
    return poses
```

1. `linspace` 把动作时间均匀采成 24 个点。`frames ** speed` 将时间变为动作进度：speed > 1 时中途进度偏小、后段追上；speed < 1 则相反。它是时间扭曲，不是增加帧数或简单的恒速倍率。
2. 四段长度乘 `scale`。5 个关节之间恰好有 4 条骨骼。`zeros` 预留 `[24,5,2]` 的输出。
3. 外层循环逐帧选择四段骨骼的角度。抬手让第一段角度随进度变化；挥手用正弦函数让第三段来回摆动，归一化进度内有两个周期；指向的角度不随时间变，因而是静止姿态。
4. 每帧从 `(0.50+root_shift,0.78)` 出发。`poses[frame_index,0]` 保存根节点。
5. `zip(lengths,angles)` 配对长度和角度，`enumerate(...,start=1)` 生成其余关节编号。每段位移为 `(side × length × cos(angle), length × sin(angle))`，叠加在上一个关节上。角度单位为弧度，且是相对全局坐标轴的角度，并未累加父骨骼角度。
6. 返回全部帧。绘图会反转 y 轴，所以 y 越小画面位置越高。坐标并未裁剪到 [0,1]；部分姿态可能被固定绘图范围截掉。

#### `make_gloss_one_hot`

原文件：`src/data.py`，第 69 行起。

```python
def make_gloss_one_hot(gloss):
    return torch.nn.functional.one_hot(gloss, num_classes=NUM_GLOSSES).float()
```

把类别编号改成 one-hot，例如 `[0,2] → [[1,0,0],[0,0,1]]`。不直接把 0、1、2 当连续数值，可避免暗示类别之间存在大小和距离关系。`.float()` 转为线性层通常使用的浮点类型。批量输入 `[B]` 变为 `[B,3]`。

#### `make_keyframe_inputs`

原文件：`src/data.py`，第 73 行起。

```python
def make_keyframe_inputs(pose):
    batch, frames, joints, xy = pose.shape
    mask = torch.zeros(batch, frames, 1, device=pose.device)
    indices = (0, frames // 2, frames - 1)
    mask[:, list(indices), :] = 1.0
    sparse_pose = pose * mask.unsqueeze(-1)
    return sparse_pose.reshape(batch, -1), mask.reshape(batch, -1), mask
```

解包 `[B,T,J,2]`；创建 `[B,T,1]` 的全零 mask，并在索引 0、12、23 置 1。这里中间帧指零起始编号 12，即第 13 帧。

`mask.unsqueeze(-1)` 变成 `[B,T,1,1]`，通过广播与每帧所有关节坐标相乘。只保留三帧，其余置零。保留 mask 是为了区分“没有给出这一帧”和“这一帧坐标真的为零”。返回稀疏坐标 `[B,240]`、展平 mask `[B,24]`、原始 mask `[B,24,1]`。`reshape(batch,-1)` 的 -1 表示自动计算剩余维度。

#### `build_condition`

原文件：`train.py`，第 44 行起。

```python
def build_condition(batch, experiment):
    gloss = make_gloss_one_hot(batch["gloss"])
    if experiment == "multi_condition":
        # 五档量化是 FSQ 思路的课堂演示，不是完整 FSQ 自编码器。
        continuous = batch["extra"].clamp(-1.0, 1.0)
        quantized = torch.round((continuous + 1.0) * 2.0) / 2.0 - 1.0
        return torch.cat([gloss, quantized], dim=1)
    return gloss
```

先生成 `[B,3]` 类别条件。只有 multi_condition 会读取额外条件：`clamp` 限制范围，公式把 [-1,1] 映射到 [0,4] 后四舍五入，再映射回来，得到 `{-1,-0.5,0,0.5,1}` 五档。

例如 0.30 会变成 0.5；方向 ±1 则保留。拼接后是 `[B,6]`。`dim=1` 表示沿特征维拼接，样本数不变。这是输入数值量化示例，没有学习编码器、码本或完整 FSQ 自编码器。量化也会丢掉部分精度。

#### `prepare_input`

原文件：`train.py`，第 71 行起。

```python
def prepare_input(batch, experiment):
    condition = build_condition(batch, experiment)
    if experiment == "keyframe":
        sparse_pose, mask_flat, mask = make_keyframe_inputs(batch["pose"])
        return torch.cat([condition, sparse_pose, mask_flat], dim=1), mask
    return condition, None
```

普通实验返回 `(condition,None)`。关键帧实验先从标准答案中抽取三帧作为已知条件，然后拼接 `[类别3, 稀疏坐标240, mask24]`，得到 `[B,267]`；另返回未展平 mask 给损失函数。

这是“已知部分动作补全其余动作”的任务，因此输入包含目标的三帧是设计的一部分。不能据此声称模型仅凭类别完成了同样的预测。

#### `pose_objective`

原文件：`train.py`，第 79 行起。

```python
def pose_objective(prediction, target, experiment, args, mask):
    loss = coordinate_loss(prediction, target)
    if experiment == "bone":
        loss = loss + args.bone_weight * bone_vector_loss(prediction, target)
    if experiment == "temporal":
        loss = loss + args.smooth_weight * velocity_loss(prediction, target)
    if experiment == "keyframe":
        loss = loss + keyframe_loss(prediction, target, mask)
    return loss
```

所有非扩散实验都包含坐标 MSE。bone 加 `0.25 × 骨骼向量 MSE`；temporal 加 `0.10 × 速度 MSE`；keyframe 加关键帧 MSE。其余实验只用坐标 MSE。

额外项相加形成一个标量，再一起反向传播。权重影响不同约束的重要程度；不同实验的总损失定义不同，不能直接以总损失数值大小判定哪个实验更好。

#### `run_epoch`

原文件：`train.py`，第 90 行起。

```python
def run_epoch(model, loader, optimizer, experiment, args, device, schedule):
    training = optimizer is not None
    model.train(training)
    total_loss = 0.0
    total_samples = 0

    for batch in loader:
        batch = {name: value.to(device) for name, value in batch.items()}
        target = batch["pose"]
        if experiment == "diffusion":
            clean = target.reshape(target.shape[0], -1)
            noise = torch.randn_like(clean)
            time_index = torch.randint(
                0, args.diffusion_steps, (target.shape[0],), device=device
            )
            noisy = add_noise(clean, noise, time_index, schedule[2])
            condition = make_gloss_one_hot(batch["gloss"])
            time = time_index.float() / max(args.diffusion_steps - 1, 1)
            prediction = model(noisy, condition, time)
            loss = F.mse_loss(prediction, noise)
        else:
            model_input, mask = prepare_input(batch, experiment)
            prediction = model(model_input)
            loss = pose_objective(prediction, target, experiment, args, mask)

        if training:
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

        count = target.shape[0]
        total_loss += loss.detach().item() * count
        total_samples += count

    return total_loss / max(total_samples, 1)
```

1. `optimizer is not None` 决定是否训练；`model.train(training)` 在训练模式与评估模式间切换。当前网络没有 Dropout/BatchNorm，两种模式的前向行为基本相同，但保留了规范接口。
2. 遍历 loader，每次拿一个批次；字典推导式把所有张量搬到同一个 CPU/GPU。`target` 为 `[B,24,5,2]`。
3. 普通分支准备条件、前向预测、计算姿态损失，输出形状与 target 一致。
4. 扩散分支把动作展平为 `[B,240]`；生成同形状的标准高斯噪声；给每个样本独立抽取时间步；按计划加噪；把时间归一化到 [0,1]；模型预测噪声，并与真实噪声计算 MSE。这里 `prediction` 的含义是噪声，不是动作。
5. 训练时先 `zero_grad()` 清除上一次梯度，再 `loss.backward()` 用链式法则计算参数梯度，最后 `optimizer.step()` 让 Adam 更新权重。若没有清零，PyTorch 默认会累积梯度。
6. `loss.detach().item()` 从计算图取出普通数值，只用来记录。损失乘批次实际样本数后累加，最后除总样本数；这样最后一个小批次不会被赋予与完整批次相同的权重。

验证调用者还要使用 `torch.no_grad()`：评估模式本身不会关闭梯度。扩散验证每次会重新抽噪声和时间步，因此验证损失可能因随机抽样而波动。

```python
@torch.no_grad()
def make_preview(model, dataset, experiment, args, device):

```

`@torch.no_grad()` 关闭本函数中的梯度记录。取验证集第 0 个样本，给每个字段增加批次维，形成 B=1 的输入。

扩散实验从随机噪声采样，再还原 `[1,24,5,2]`；其余实验直接前向。`[0]` 去掉批次维，`.cpu().numpy()` 把结果交给绘图库。返回目标、预测、类别编号。

这里只画一个样本，不能代表整个验证集。非扩散分支依靠上一轮验证留下的 eval 模式；若脱离 main 单独调用，宜显式设置 `model.eval()`。

## 第三章：基础模型、时序模型和损失

| 实验 | 输入 | 网络 | 目标 |
| --- | --- | --- | --- |
| baseline | 类别 | MLP | 坐标 MSE |
| bone | 类别 | 同一个 MLP 结构 | 坐标 + 骨骼向量误差 |

baseline 与 bone 可以观察只改损失的影响。但 temporal 同时换了网络和损失，当前代码不能把其差异单独归因于时间卷积。若要严格对照，可在掌握后设计“同网络有/无速度损失”等实验。

同一类别的目标存在左右方向、尺度、位置和速度变化，而 baseline 只收到类别。确定性模型对同一输入只能输出同一结果；平方误差会推动它接近条件均值。左右镜像平均后，预测可能靠近根节点，出现幅度缩小。这未必是反向传播写错，而是条件信息不足与损失选择共同导致的。


## 第三章 A：逐个网络解析（进阶网络可稍后返回阅读）

`nn.Module` 是网络基类；`super().__init__()` 初始化模块管理机制，使层的参数能被 `parameters()` 找到。`__init__` 定义可训练层，`forward` 描述输入怎样变为输出。调用 `model(x)` 时 PyTorch 会进入 forward，并处理相关模块机制。

`nn.Linear(in,out)` 对最后一维做仿射变换 `y=xWᵀ+b`；`ReLU` 逐元素取 `max(0,x)`，提供非线性；`Sequential` 依次运行其中的层。

### `PoseMLP`

基础网络一次输出全部帧坐标，不需要逐帧循环。baseline 和 bone 都使用它。

#### `PoseMLP.__init__`

原文件：`src/models.py`，第 8 行起。

```python
def __init__(self, condition_dim, hidden_dim=256):
    super().__init__()
    self.network = nn.Sequential(
        nn.Linear(condition_dim, hidden_dim),
        nn.ReLU(),
        nn.Linear(hidden_dim, NUM_FRAMES * POSE_DIM),

```

默认构成 `3 → 256 → 240`。隐藏维 256 是可调的容量设置，240 来自 24 帧 × 5 点 × 2 坐标。末层没有激活函数，所以坐标可超出 [0,1]。baseline 参数数为 `(3×256+256)+(256×240+240)=62704`。

#### `PoseMLP.forward`

原文件：`src/models.py`，第 16 行起。

```python

    return output.reshape(-1, NUM_FRAMES, POSE_DIM // 2, 2)
```

`[B,3] → [B,240] → [B,24,5,2]`。reshape 只重新解释维度，不额外学习，也不把动作按时间递归生成。-1 在这里自动推断批次大小。

### `TemporalPoseNet`

先根据类别和当前时间生成每帧粗预测，再利用一维卷积混合相邻时间的信息。

#### `TemporalPoseNet.__init__`

原文件：`src/models.py`，第 22 行起。

```python
def __init__(self, condition_dim, hidden_dim=64):
    super().__init__()
    self.frame_mlp = nn.Sequential(
        nn.Linear(condition_dim + 1, hidden_dim),
        nn.ReLU(),
        nn.Linear(hidden_dim, POSE_DIM),
    )
    self.temporal = nn.Sequential(
        nn.Conv1d(POSE_DIM, hidden_dim, 3, padding=1),
        nn.ReLU(),
        nn.Conv1d(hidden_dim, POSE_DIM, 3, padding=1),
    )
```

`frame_mlp` 接收类别条件加 1 个时间值，做 `4→64→10`。`temporal` 做通道 `10→64→10` 的两层时间卷积；核宽 3，默认步幅 1，padding=1 让输出帧数仍为 24。这里的通道是坐标特征，卷积移动的方向是时间。

#### `TemporalPoseNet.forward`

原文件：`src/models.py`，第 35 行起。

```python
def forward(self, condition):
    batch = condition.shape[0]
    time = torch.linspace(0, 1, NUM_FRAMES, device=condition.device)
    time = time.view(1, NUM_FRAMES, 1).expand(batch, -1, -1)
    repeated = condition.unsqueeze(1).expand(-1, NUM_FRAMES, -1)
    coarse = self.frame_mlp(torch.cat([repeated, time], dim=-1))
    residual = self.temporal(coarse.transpose(1, 2)).transpose(1, 2)
    pose = coarse + residual
    return pose.reshape(-1, NUM_FRAMES, POSE_DIM // 2, 2)
```

1. 在输入所在设备创建 `[24]` 时间序列，经 view 和 expand 得到 `[B,24,1]`。
2. 类别条件从 `[B,3]` 扩展为 `[B,24,3]`，每帧都收到同一类别；expand 是扩展视图，通常不实际复制全部数据。
3. 拼接为 `[B,24,4]`，MLP 对最后一维运算，得到 coarse `[B,24,10]`。
4. Conv1d 要求 `[B,通道,时间]`，因此转置为 `[B,10,24]`；卷积后再转回来。
5. `coarse+residual` 表示在粗预测上学习修正量。两层宽 3 卷积在粗特征上的局部感受野最多为 5 帧，边界使用零填充。最终整理为标准姿态形状。

它一次处理整段序列，能看见相邻前后帧，不是只能看过去的自回归模型。

## 第三章 B：逐个损失解析

损失把“预测哪里不好”变成可求导的标量。`F.mse_loss(a,b)` 默认对所有元素求平方误差的平均值。数值越小表示按该度量越接近，并不等于动作一定符合真实手语语义。

### 导入与文件级定义

```python
"""易读的姿态坐标、骨骼、速度和关键帧损失。"""
import torch.nn.functional as F
```

#### `coordinate_loss`

原文件：`src/losses.py`，第 5 行起。

```python
def coordinate_loss(prediction, target):
    return F.mse_loss(prediction, target)
```

对 `[B,24,5,2]` 全部坐标计算 MSE：`Σ(pred-target)²/(B×24×5×2)`。例如单个坐标误差 0.1，其平方误差是 0.01；其他元素还会参与平均。

#### `bone_vector_loss`

原文件：`src/losses.py`，第 9 行起。

```python
def bone_vector_loss(prediction, target):
    pred_bones = prediction[:, :, 1:] - prediction[:, :, :-1]
    target_bones = target[:, :, 1:] - target[:, :, :-1]
    return F.mse_loss(pred_bones, target_bones)
```

`[:,:,1:]` 选择后四个关节，`[:,:,:-1]` 选择前四个关节；相减得到四条骨骼向量 `[B,24,4,2]`。比较的是向量，既包含长度又包含方向，并非仅约束骨长。

整条链统一平移时骨骼向量不变，所以骨骼损失不能单独确定绝对位置，这也是仍保留坐标损失的原因。

#### `velocity_loss`

原文件：`src/losses.py`，第 15 行起。

```python
def velocity_loss(prediction, target):
    pred_velocity = prediction[:, 1:] - prediction[:, :-1]
    target_velocity = target[:, 1:] - target[:, :-1]
    return F.mse_loss(pred_velocity, target_velocity)
```

这里沿时间轴做差，得到 `[B,23,5,2]` 的每帧位移。时间间隔按 1 帧处理，没有除以真实秒数。

比较预测位移与目标位移，鼓励学对运动变化。虽然参数名叫 smooth_weight，但这不是直接把速度压到 0 的平滑惩罚，也没有计算加速度；目标里有快速运动时它会鼓励跟上快速运动。

#### `keyframe_loss`

原文件：`src/losses.py`，第 21 行起。

```python
def keyframe_loss(prediction, target, keyframe_mask):
    mask = keyframe_mask.unsqueeze(-1)
    error = (prediction - target).pow(2) * mask
    return error.sum() / mask.sum().clamp_min(1.0) / prediction.shape[2] / 2
```

mask 从 `[B,24,1]` 扩为 `[B,24,1,1]`，广播到坐标误差，只保留三帧。先求误差和，再除已知帧数、关节数、坐标维数，因此是已知坐标的平均平方误差。`clamp_min(1.0)` 防止 mask 全零时除以零。

总目标里已含所有帧的坐标 MSE，这一项又单独强调已知帧。当前每段 3 帧已知：单个关键帧坐标在总目标中的系数为 `1/(B×24×10)+1/(B×3×10)`，是普通坐标的 9 倍。

## 第四章：扩散模型的训练与采样

先区分：数据集的 24 帧是动作时间；扩散的 50 步是加噪/去噪时间。一次扩散更新会处理整段动作的 240 个坐标，不是生成一帧。

### 导入与文件级定义

```python
"""最小化的 DDPM 教学实现。"""
import torch
```

#### `make_noise_schedule`

原文件：`src/diffusion.py`，第 5 行起。

```python
def make_noise_schedule(steps, device):
    beta = torch.linspace(1e-4, 0.02, steps, device=device)
    alpha = 1.0 - beta
    alpha_bar = torch.cumprod(alpha, dim=0)
    return beta, alpha, alpha_bar
```

`beta` 是每步噪声强度，线性从 0.0001 增到 0.02；`alpha=1-beta` 是每步保留信号的比例；`cumprod` 得到累计保留量 ᾱ。三者形状均为 `[steps]`，并创建在指定设备。

噪声计划没有可训练参数。ᾱ 不是普通求和；多个步骤的信号衰减要连乘。

#### `add_noise`

原文件：`src/diffusion.py`，第 12 行起。

```python
def add_noise(clean_pose, noise, time_index, alpha_bar):
    selected = alpha_bar[time_index].unsqueeze(1)
    return selected.sqrt() * clean_pose + (1.0 - selected).sqrt() * noise
```

`time_index:[B]` 为各样本选出不同的 ᾱ，经 unsqueeze 变为 `[B,1]`，可广播到 `[B,240]`。

公式：`x_t = sqrt(ᾱ_t) x_0 + sqrt(1-ᾱ_t) ε`，其中 ε 是标准高斯噪声。这能直接构造任意时间步的含噪动作，训练不必先循环执行前面所有加噪步骤。网络学习恢复 ε，而非直接背诵 x_0。

#### `sample_pose`

原文件：`src/diffusion.py`，第 17 行起。

```python
@torch.no_grad()
def sample_pose(model, condition, steps, pose_dim, device):
    beta, alpha, alpha_bar = make_noise_schedule(steps, device)
    pose = torch.randn(condition.shape[0], pose_dim, device=device)
    model.eval()

    for step in reversed(range(steps)):
        time = torch.full(
            (condition.shape[0],), step / max(steps - 1, 1), device=device
        )
        predicted_noise = model(pose, condition, time)
        beta_t = beta[step]
        alpha_t = alpha[step]
        alpha_bar_t = alpha_bar[step]
        pose = pose - beta_t / torch.sqrt(1.0 - alpha_bar_t) * predicted_noise
        pose = pose / torch.sqrt(alpha_t)
        if step > 0:
            pose = pose + torch.sqrt(beta_t) * torch.randn_like(pose)
    return pose
```

1. `@torch.no_grad()` 不建梯度图，`model.eval()` 切换评估模式。
2. 从 `[B,240]` 的标准高斯随机数开始生成。不同初始噪声可产生不同结果。
3. 从 steps-1 倒数到 0，构造与训练一致的归一化时间，预测当前动作中的噪声。
4. 两次赋值合起来实现均值更新：`μ=(x_t-β_t/sqrt(1-ᾱ_t)×εθ)/sqrt(α_t)`。
5. 不是最后一步时，再加 `sqrt(β_t)×z`。这是使用 β_t 作为反向过程方差的简化选择，并非精确后验方差公式。最后一步不再加随机噪声。
6. 返回展平动作，由调用者 reshape。

重要局限：默认只有 50 步且 beta 上限为 0.02，末端 ᾱ 约 0.60，信号系数仍约 0.78，因此训练末端分布未充分接近采样起点的纯高斯噪声。这个教学配置可能生成较差；噪声预测损失下降也不能保证采样质量。理解流程后可研究更长时间表或更合适的计划。

## 第五章：把三个进阶实验串起来

### 多条件 multi_condition

数据中的 extra → build_condition 五档量化 → 类别与额外条件拼成 6 维 → PoseMLP → 坐标 MSE。

额外条件让网络能区分左右、体型和水平位置，减少“同输入对应不同答案”的歧义。量化后的尺度/位置仍有信息损失，速度也没有输入，因此无法据此期待每个目标都被精确恢复。这个实验没有继承 bone 或 temporal 的额外损失。

### 多头 multi_head

类别 3 维 → shared 128 维 → 身体头 144 维与手部头 96 维 → 按关节拼接 → 坐标 MSE。

拆分输出有助于理解共享表示与任务分支，但此处没有真实手部细节、独立手部条件或专门损失。只用类别仍然存在平均动作问题；多一个头不会自动补齐缺失条件。

### 关键帧 keyframe

类别 + 三帧真实坐标 + mask → 267 维输入 → KeyframePoseNet → 预测全部 24 帧 → 全序列坐标 MSE + 关键帧 MSE。

训练和预览都会从目标提供三帧。应用时也需要已知关键帧；不能在没有关键帧的情况下照搬这个输入接口。它没有从目标读取其余帧作为输入，但这些帧会作为监督答案参与损失。

七个 experiment 是分别选择的分支，并非自动层层叠加。不要把 multi_head 理解为“扩散 + 多条件 + 多头”的综合系统。

#### `draw_pose_sequence`

```python
def draw_pose_sequence(axis, pose, title):
    pose = np.asarray(pose)
    frames = np.linspace(0, len(pose) - 1, 6, dtype=int)
    colors = plt.cm.viridis(np.linspace(0.15, 0.95, len(frames)))
    for frame, color in zip(frames, colors):
        points = pose[frame]
        for start, end in BONES:
            axis.plot(
                [points[start, 0], points[end, 0]],
                [points[start, 1], points[end, 1]],
                color=color, alpha=0.75, linewidth=2,
            )
        axis.scatter(points[:, 0], points[:, 1], color=[color], s=18)
    axis.set_title(title)
    axis.set_xlim(0, 1)
    axis.set_ylim(1, 0)
    axis.set_aspect("equal")
    axis.grid(True, alpha=0.2)
```

将数据变成 NumPy 数组；在全序列中均匀抽 6 帧，24 帧时索引是 0、4、9、13、18、23。viridis 为各帧分配从早到晚的颜色。

对每帧按 BONES 连接关节，再用散点显示关节。`alpha` 控制透明度，linewidth/s 控制线宽和点大小。设标题、坐标范围和等比例显示，避免骨骼因横纵比例不同看起来变形。`ylim(1,0)` 使 y 轴朝下，贴近图像坐标。这里是多帧叠图，不是动画。

扩散先关注“随机噪声是真实标签，模型输出是预测噪声”，再关注采样循环；不要把扩散 MSE 与坐标 MSE 相比较。20 轮只是代码默认设置，不保证每个实验都充分收敛。

### 4. 用几个问题检查理解

- 为什么一个动作有 240 个数，而不是 24 个类别？因为模型回归所有帧所有点的坐标。
- 为什么需要隐藏层激活？没有非线性时，多层线性变换整体仍是线性变换。
- 验证为什么不更新参数？它检验对训练外样本的表现；参与更新会失去这层意义。
- 骨骼损失能否确定根节点位置？不能，整体平移不改变骨骼向量。
- 关键帧为什么要传 mask？零坐标也可能是真实值，不能仅凭零识别缺失。
- 扩散是否每次预测一帧？不是，它每步预测整段动作向量里的噪声。

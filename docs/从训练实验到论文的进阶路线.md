# 从训练实验到手语生成论文的进阶路线

本文承接[代码逐段解说](代码逐段解说.md)，把当前的二维合成动作实验与五篇论文连接起来。目标是通过可解释的小实验读懂方法，而不是立刻复现完整系统。

文中“建议新增”的模块与实验尚未实现，不能直接作为 `--experiment` 参数运行。已有实验仍以 README 和 `train.py` 为准。论文分析依据用户提供的本地 PDF，来源见文末。

## 1. 总路线与阅读顺序

建议按知识依赖阅读，而不是按 PDF 文件编号阅读：

**当前实验 → Sign-IDD → FGDM → SignSparK → SOKE → SignViP。**

这条路线包含两种主要生成思路：

```text
共同基础：数据、训练、条件输入、时空建模、评价
    │
    ├─ 连续生成：扩散 → 骨骼表示 → 局部/全局关系 → 关键帧 Flow Matching
    │              Sign-IDD       FGDM              SignSparK
    │
    └─ 离散生成：自编码器 → 量化 token → 自回归预测 → 多条件视频系统
                                          SOKE           SignViP
```

不需要先学会所有数学或读完所有相关论文。每进入一个阶段，补齐对应概念，做一个小对照，再回到论文。

| 层面 | 当前项目 | 论文逐步增加的内容 |
| --- | --- | --- |
| 条件 | 单个动作类别 | gloss 序列、自然语言、关键帧、参考图像 |
| 输出 | 固定 24 帧、5 个二维点 | 变长三维动作、人体参数、视频 |
| 空间结构 | 简单关节链 | 骨骼拓扑、身体与双手关联 |
| 网络 | MLP、时间卷积 | 图卷积、注意力、Transformer、U-Net |
| 生成 | 回归、简化 DDPM | 条件扩散、Flow Matching、自回归 token 预测 |
| 监督 | 坐标、骨骼向量、速度 | 语义一致性、量化重建、多阶段目标 |
| 评价 | 损失、单个样本叠图 | 几何、语义、自然度、多样性与计算成本 |

### 先分清几个术语

- **gloss**：用于标注手语词项的书写标签，不等于自然语言的逐词翻译。
- **motion token**：学习得到的离散动作编码，不保证一个 token 对应一个完整手语词。
- **latent / embedding**：模型内部的连续特征表示，不必直接具有坐标含义。
- **动作时间**：序列中的帧位置；本项目有 24 帧。
- **扩散或流时间**：从噪声走向数据、或从数据加噪的生成过程时间，与动作帧数无关。
- **训练目标**：网络实际回归或分类的量。不同方法可能预测噪声、干净动作、速度场或 token。

## 2. 第一阶段：真正掌握当前训练实验

### 2.1 需要掌握的基础

结合 `src/data.py`、`src/models.py`、`src/losses.py` 和 `train.py`，做到：

1. 能解释 `[B,24,5,2]`，以及展平后为什么是 `[B,240]`。
2. 能跟踪输入、前向预测、标量损失、反向传播和 Adam 更新。
3. 能区分训练集、验证集、epoch、batch、参数和超参数。
4. 能解释 `model.eval()` 与 `torch.no_grad()` 的不同职责。
5. 能说明同一类别存在多种目标时，确定性 MSE 回归为什么倾向条件均值。

### 2.2 建议先做的实验

**实验 A：只记住一个小批次。**

固定少量样本，反复训练。目的不是评价泛化，而是检查网络和训练流程是否具有基本拟合能力。如果连固定小批次都拟合不了，先排查输入、目标、梯度与优化设置。

**实验 B：消除输入歧义，再逐个恢复变化。**

暂时固定方向、长度、根节点位置和速度，只保留类别变化。再每次恢复一个随机因素，分别比较“不给模型该条件”和“把该条件也输入模型”。

这能区分容量不足、训练不足与条件信息缺失。当前 `extra` 没有包含速度，因此 multi_condition 也不是完全确定目标的输入。

**实验 C：拆开记录指标。**

除训练总目标外，分别记录坐标 MSE、骨骼向量误差和相邻帧位移误差；在固定验证集上评价多个样本，避免只观察第一个样本。

### 2.3 通过标准

能够独立说明一次参数更新发生了什么，并根据输入信息解释预测为何出现平均化。不要仅以“loss 下降”作为理解完成的标准。

注意：当前 baseline 与 bone 网络相同，可用于观察增加损失项的影响；temporal 同时改变网络和损失，不能把全部差异单独归因于时间卷积。

## 3. 第二阶段：骨骼方向与长度 → Sign-IDD

对应论文：**Sign-IDD: Iconicity Disentangled Diffusion for Sign Language Production**。建议先读 Figure 1、整体框架，再读 Iconicity Disentanglement、Attribute Controllable Diffusion 和损失部分。

### 3.1 要解决的问题

关节绝对坐标接近目标，仍可能出现骨骼方向偏差、肢体形变或手指结构错误。单独拟合点的位置，对关节之间的关系表达不够直接。

当前 `bone_vector_loss` 已经提供入口：

```python
pred_bones = prediction[:, :, 1:] - prediction[:, :, :-1]
```

它比较相邻点的位移向量，同时涉及方向与长度，不是纯骨长约束。

### 3.2 论文增加了什么

对父关节与子关节，定义：

\[
b=p_{\text{child}}-p_{\text{parent}},\qquad
\ell=\|b\|_2,\qquad d=b/\ell.
\]

三维单位方向 `d` 加一维长度 `ℓ` 构成四维骨骼表示。论文将其与三维坐标结合，形成七维特征，并通过属性分离与控制模块进行条件去噪。

因此完整方法不仅改变损失，还改变了输入表示和网络内部处理方式。论文的骨骼监督也不能直接等同于项目现有的未归一化骨骼向量 MSE。

### 3.3 建议实现的二维缩小版

```text
二维坐标 → 相邻点差分 → 二维单位方向 + 一维长度
                                     ↓
                            与坐标特征一起输入网络
```

建议依次比较：

| 对照 | 改变什么 | 观察什么 |
| --- | --- | --- |
| 坐标回归 | 基线 | 位置与形状误差 |
| 坐标 + 骨骼向量损失 | 增加已有约束 | 整体结构 |
| 坐标 + 单位方向损失 | 单独强调方向 | 方向误差与骨长误差是否分别改善 |
| 输入增加方向、长度特征 | 改变表示 | 表示增强是否有帮助 |

实现时用小正数保护长度分母，并明确根节点、骨骼与关节之间的索引关系。真实骨架应使用父节点表，不能默认所有相邻编号都由一条骨骼相连。

**通过标准：**能解释“改表示”“改网络”“改损失”的区别，能画出坐标与骨骼表示之间的转换关系。

## 4. 第三阶段：局部、全局与语义监督 → FGDM

对应论文：**Focal–General Diffusion Model with Semantic Consistent Guidance for Sign Language Production**。优先阅读 Figure 2、Figure 3，以及 Focal、General、Semantic Consistent Guidance 三部分。

### 4.1 论文的主线

```text
含噪姿态 + gloss 条件
          ↓
Focal：局部关节关系与时间变化
          ↓
General：全局序列一致性
          ↓
预测干净姿态

同时：视觉特征 → 语义空间 → gloss 序列监督
```

Focal 使用自适应图卷积 ASGCN 与时间卷积；General 使用 Transformer。这里的两阶段首先是去噪网络内部的处理阶段，不等于两个独立训练的生成模型。

语义一致性 SCG 通过视觉到语义的适配器、语义解码器和带扩散时间权重的 CTC 目标实现。论文还使用了 Iconicity Disentanglement 增强表示，因此读完 Sign-IDD 再读它更顺畅。

### 4.2 需要补的知识

| 概念 | 先理解的问题 |
| --- | --- |
| 邻接矩阵与 GCN | 某个关节应该从哪些关节聚合信息？ |
| 时间卷积 | 局部前后帧如何相互影响？ |
| Self-attention | 当前帧如何参考远处帧？ |
| Cross-attention | 动作特征如何读取 gloss 特征？ |
| CTC | 没有逐帧标签时，如何对齐帧序列与较短标签序列？ |

### 4.3 三个递进实验

1. 给五关节链建立固定邻接矩阵，写一个最小邻居聚合模块。先理解固定图，再研究自适应图。
2. 使用小型 Transformer 处理时间特征，与时间卷积进行对照。不要同时改变损失、数据和隐藏维，否则难以判断改进来自哪里。
3. 先训练动作分类器，用分类信号约束生成动作。这个实验只演示语义监督；它不等价于论文 SCG。还要警惕生成器利用分类器弱点，因此应使用独立评价与可视化。

当前每段只有一个类别，可先用交叉熵。之后把数据扩展为“多个动作标签对应一个变长序列”，引入 padding、有效帧 mask、输入长度和目标长度，再学习 CTC。

**通过标准：**能说明为什么坐标误差小、动作平滑，仍可能语义错误；能区分训练中的语义辅助损失与采样时的 guidance。

## 5. 第四阶段：关键帧与 Flow Matching → SignSparK

对应论文：**SignSparK**（提供的稀疏关键帧学习 PDF）。优先阅读 Figure 3、Section 3.2 以及关键帧、损失和采样步数相关消融。

### 5.1 当前实验与论文的距离

当前 keyframe 使用固定三帧、mask 和类别条件，通过 MLP 一次回归整段动作。论文结合了：

- 由 FAST 定位片段并选择有意义的关键帧。
- 稀疏关键帧和文本条件。
- 条件 Flow Matching 网络。
- 重建与动作相邻帧位移约束。
- 三维人体、手部与面部表示，以及后续渲染。

学习阶段先聚焦关键帧与生成过程，暂时不做人体拟合和照片级渲染。

### 5.2 先掌握基础线性 Flow Matching

以下是基础教学形式，不是对 SignSparK 全部公式的直接转写。约定 `z` 为噪声、`x` 为真实动作、`t=0` 为噪声端、`t=1` 为数据端：

\[
x_t=(1-t)z+tx,\qquad u=x-z.
\]

网络输入中间状态、流时间和条件，回归目标速度 `u`。采样从噪声出发，用 ODE 求解器更新状态。

```python
# clean、noise: [B, 240]；condition: [B, C]
noise = torch.randn_like(clean)
t = torch.rand(clean.shape[0], device=clean.device)
mixed = (1 - t[:, None]) * noise + t[:, None] * clean
predicted_velocity = model(mixed, condition, t)
loss = F.mse_loss(predicted_velocity, clean - noise)
```

这只是训练片段，仍需要优化器、训练循环和匹配的采样器。网络输出形状可以复用现有 NoisePredictor 的设计，但语义由“噪声”改为“速度”，必须重新训练。

这里速度是整段动作向量在生成过程中的变化率；`velocity_loss` 则是动作相邻帧的位移误差，二者不可混用。

### 5.3 递进对照

| 步骤 | 实验 | 目的 |
| --- | --- | --- |
| 1 | 已知帧之间线性插值 | 建立无学习基线 |
| 2 | 当前关键帧 MLP | 判断学习补全的价值 |
| 3 | 类别条件基础 FM | 理解从随机噪声到动作 |
| 4 | 关键帧条件 FM | 同时学习锚点控制与中间运动 |
| 5 | 固定、随机、运动转折关键帧对照 | 判断关键帧信息量的影响 |

关键帧条件可以作为额外输入，也可以在生成状态中保留已知值；两种方式的目标和采样处理需要明确。当前 MLP 没有硬性覆盖已知帧，因此不能保证已知帧完全一致。

分别记录已知帧误差、未知帧误差、速度误差与采样时间，比较多个采样步数。若评估多样性，使用多个随机种子，不要把某个随机样本未逐点匹配唯一目标直接解释为生成失败。

### 5.4 阅读公式时需要核查的地方

提供版本式（3）将目标写为 `x1 - Ct`，而基础线性路径的常见速度目标为 `x1 - x0`；式（4）的重建还使用剩余时间因子。应核对状态定义、输出参数化、论文补充材料和代码中的更新规则，不要默认所有写作“velocity”的量完全相同。

本文保留这个核查点，不据此替作者改写公式，也不把上面的基础 FM 片段称为论文复现。

**通过标准：**能分别解释关键帧提供什么、模型学习什么、求解器执行什么；能够区分基础 FM 与论文具体参数化。

## 6. 第五阶段：连续动作变成 token → SOKE

对应论文：**Signs as Tokens: A Retrieval-Enhanced Multilingual Sign Language Generator**。优先阅读 Figure 2、Figure 3、Decoupled Tokenizer 与 Autoregressive Multilingual Generator。

### 6.1 两阶段思路

```text
阶段一：动作 → 身体/左手/右手 tokenizer → 离散 token → 重建动作
阶段二：文本 + 检索词典动作 → 自回归预测 token → 解码动作
```

论文使用解耦的 VQ-VAE 分别处理身体、左手与右手。多头解码在每个解码位置同时预测各部位 token，并融合部位信息，避免把所有部位 token 展平成更长序列后逐个生成。

项目现有 multi_head 是连续坐标输出；这里的多头输出是离散类别分布。它们共享“共享特征后分支”的想法，但输出含义和训练目标不同。

### 6.2 四个建议实验

1. **连续自编码器**：`[B,T,D] → [B,K,C] → [B,T,D]`，先检查瓶颈大小与时间下采样如何影响重建。
2. **VQ tokenizer**：把连续 latent 替换为最近的码本向量，学习重建、码本和 commitment 目标，并理解直通梯度估计。
3. **token 预测器**：冻结 tokenizer，先由类别预测 token，再增加短标签序列条件。输出形状通常为 `[B,K,V]`，监督 token ID 为 `[B,K]`，其中 V 是码本类别数。
4. **分部位和自回归**：将身体与手部拆开，逐步引入因果 mask、teacher forcing、起止 token，再比较单序列解码和多头解码。

五关节链只能演示分支机制，不能模拟双手与身体的真实信息结构；需要更丰富合成骨架后再评价分部位优势。

### 6.3 关键评价拆分

- **tokenizer 重建质量**：真实动作经过编码、量化、解码后保留多少信息？
- **条件生成质量**：预测 token 解码出的动作是否正确？
- **码本使用情况**：是否少量 token 被反复使用，其他 token 很少出现？
- **自回归效率**：生成长度与解码调用次数怎样变化？

前者形成表示的能力边界。如果 tokenizer 已丢掉手部细节，后面的语言模型很难恢复。检索增强、多语言与预训练大模型应放在基础流程之后。

**通过标准：**能说明为什么连续回归变成离散分类，以及 tokenization 误差如何影响最终动作。

## 7. 第六阶段：多条件 token 与视频扩散 → SignViP

对应论文：**Advanced Sign Language Video Generation with Compressed and Quantized Multi-Condition Tokenization**。优先阅读 Figure 2、Section 3.3 的三个训练步骤，以及 FSQ Autoencoder 和 Token Translator。

### 7.1 整体流程

```text
文本 → 多条件 token 翻译器 → FSQ 解码 → 连续条件 embedding
                                                   ↓
参考人物图像 ───────────────────────────────→ 视频扩散模型 → 视频
```

SignViP 的最终目标是保留目标人物身份的手语视频。它压缩和量化的是学习得到的多条件 embedding，不是简单地把三个手工标量四舍五入。

### 7.2 三个训练步骤

| 步骤 | 学习内容 | 主要监督 |
| --- | --- | --- |
| I | 多条件编码器与视频扩散模型联合学习 | 视频去噪目标 |
| II | FSQ 自编码器压缩、量化并重建条件 embedding | embedding 重建误差 |
| III | 文本到多条件 token 的自回归翻译器 | 目标 token 的预测监督 |

阅读时应逐阶段标明训练与冻结的模块，以及目标 token 从哪里获得。训练可以利用真实条件构造监督，推理则依赖文本预测条件，必须关注这种条件来源变化带来的误差传播。

### 7.3 建议缩小实验

先实现：

```text
合成动作条件 → 编码器 → FSQ → 解码器 → 重建条件
```

再用小网络由标签预测离散 token，最后让重建条件驱动一个小型动作生成器。这个练习学习的是压缩、条件翻译与误差传递，不是视频质量。

需要补齐 FSQ 的梯度处理：当前项目对原始输入做 round 不妨碍训练 MLP，但学习型编码器前面若直接放不可导 round，不能据此期待正常训练整个编码器，应理解直通估计等处理方式。

SOKE 与 SignViP 都使用离散表示，但 SOKE 主要对动作进行分部位 tokenization，SignViP 则建立服务于视频生成的多条件 token 空间，不能视为同一个系统。

**通过标准：**能画出三个阶段的数据流、监督流和推理路径，说明为什么使用离散中间表示。

## 8. 如何逐步加入真实任务复杂度

不要一次替换所有模块。建议按以下次序迁移：

1. 固定长度单动作 → 多动作标签与变长序列，加入 padding 和有效帧 mask。
2. 二维关节链 → 更丰富拓扑，再加入三维位置和归一化。
3. 三维关节坐标 → 人体参数、关节旋转、前向运动学；理解旋转表示后再处理 SMPL-X、MANO、FLAME。
4. 小型生成网络 → 更强时空网络与文本条件。
5. 小规模可控数据 → 真实数据与划分、缺失观测、估计噪声问题。
6. 动作生成 → 人体或视频渲染，分别评价运动与外观。

真实姿态估计产生的伪真值可能不准确；更贴近伪标签不一定代表真实动作更好。多语言手语也不是简单更换文本语言标签，需要考虑语言、数据分布和动作语义。

## 9. 评价与对照实验规范

| 维度 | 小实验先记录什么 | 注意事项 |
| --- | --- | --- |
| 几何 | 坐标、骨长、方向误差 | 对齐与归一化会改变含义 |
| 时间 | 相邻帧位移误差、轨迹图 | 平滑不等于语义正确 |
| 关键帧 | 已知与未知帧分别评价 | 已知帧误差低不能证明补全好 |
| 语义 | 独立分类器或识别器结果 | 分类器有偏差，仍需观察与人工判断 |
| 表示 | 重建误差、码本使用率 | 先区分表示能力与生成能力 |
| 多样性 | 同条件多个随机样本 | 多样性要与有效性一起考察 |
| 效率 | 参数量、网络调用次数、采样耗时 | 固定设备、批大小与计时方式 |

进入真实数据后再理解论文使用的 MPJPE、DTW 对齐、识别回译、BLEU/WER、视频质量指标等；不同论文的任务、数据划分和评价器不同，数值不能随意横向比较。手语是否正确与自然，最终仍需要合适的人类评价。

每次对照尽量只改一个因素，保持训练预算、样本、验证集与评价流程一致。随机生成实验应检查多个种子，避免把单次偶然表现当成结论。

## 10. 里程碑与论文阅读记录

| 里程碑 | 需要完成 | 对应论文 |
| --- | --- | --- |
| A | 当前训练流程；骨骼方向/长度；基础图卷积与注意力 | Sign-IDD、FGDM |
| B | 基础 FM；关键帧条件；插值对照；步数比较 | SignSparK |
| C | 自编码器；VQ/FSQ；token 分类与自回归 | SOKE、SignViP |

无需按固定周数赶进度。每个阶段保留一份可复现配置、结果表、几张代表性轨迹和一段结论，再进入下一阶段。

每篇论文按三遍阅读：

1. **任务与图**：读摘要、整体框架和结论，画出输入输出及模块关系。
2. **张量与目标**：跟踪形状，明确每个网络输出和损失标签；单独画训练与推理。
3. **证据与局限**：读消融、评价协议、失败样例，检查贡献是否被对照支持。

建议为每篇记录以下问题：

- 输入、输出分别是什么？
- 要解决哪一种具体失败现象？
- 相比基线，表示、网络、训练目标、采样各改变了什么？
- 每个公式中的时间是帧时间还是生成时间？
- 训练时可用的条件，推理时是否仍然可用？
- 多阶段方法中，谁训练、谁冻结、标签由谁生成？
- 消融是否单独检验了声称的贡献？
- 哪个结论能在当前玩具数据上验证，哪个必须依赖真实手语数据？

**建议下一项实际工作：二维骨骼单位方向与长度实验。**它连接现有 bone 分支与 Sign-IDD，改动范围小，也为后续时空建模建立共同表示基础。
